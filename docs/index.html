02 / FROM LIGHT TO INPUT

The camera sees a hand.
The Mac gets intent.

Apple Vision estimates hand joints on the phone. A small stream of observations crosses the local network. The Mac handles smoothing, gesture state and operating-system input.

Joints into intent

The middle knuckle anchors pointing. Thumb/index distance estimates a pinch. Visible finger curl identifies a fist.

Bonjour finds the Mac. Acknowledged TCP carries position and gesture flags. Camera frames stay on the phone.

INSIDE A PACKETx, yvalid, pinchValidpinched, scrollPosesequence, analysisMS

Steady when still. Gentle when precise.

A One Euro filter reduces jitter. A small dead zone absorbs tiny excursions. Fine movement uses 30% of normal gain, rising smoothly to a fixed ceiling. Faster motion does not add an extra speed boost.

Tracking loss has a defined outcome.

Lost palm tracking stops input and releases held clicks. Brief scroll-pose gaps freeze scrolling and retain the mode for 0.35 seconds. Reacquisition resets the movement anchor to avoid a jump.

Local does not mean secured: the prototype’s TCP stream has no application-level authentication or encryption. Use a trusted network. Authenticated pairing belongs on the roadmap before broader use.
03 / THE EXPERIMENT LOG

Built by trying it.
Improved by feeling it.

The important changes came from using a real hand in front of a real camera—not from adding more gestures.

01

Color won the first comparison.

DEPTH MAP → RGB CAMERA

Depth frames produced hand-joint candidates, but dots vanished during pinches. The tester found RGB substantially more consistent in normal lighting. Dark-room performance remains untested.

02

Give the hand room.

PORTRAIT → LANDSCAPE

The hand kept leaving the narrow view. Rotating the camera and interface together made the setup feel better. Palm movement also continues when pinch joints become unclear.

03

Precision beats acceleration.

DIRECT MAPPING → RELATIVE MOTION

Breathing and tiny arm movements made the pointer unstable. Relative motion, adaptive smoothing and extra-slow fine adjustment replaced the need to hit exact camera coordinates.

04

The simplest pose felt best.

TWO FINGERS → THUMB → FIST

The two-finger pose dropped during movement; thumbs-up felt awkward. Fist scrolling worked well. A requested 50% speed increase was subsequently confirmed by the tester.

05 / OPEN THE HOOD

Native Swift.
Small moving parts.

A camera app, a shared packet format and a native Mac receiver. The working apps are still named TrueDepth Probe and Hand Control. PalmRay is the project’s working name.

FROM THE SOURCE ROOT
# Build Mac app + run regression checks
./HandControl/build.sh
open HandControl/build/HandControl.app

# Generate the iPhone project
cd TrueDepthProbe
xcodegen generate
open TrueDepthProbe.xcodeproj

Use Xcode and your own Apple signing team. Tested with Xcode 27.2 and iPhone 16e. Other hardware is unvalidated; ordinary front-camera discovery still needs adaptation for RGB-only phones.

  1. Start with the practice window.
    Allow camera and Local Network access. Turn the phone sideways and start RGB → Mac.
  2. Learn three gestures.
    Open hand to point. Pinch with other fingers open to click or drag. Make a fist to scroll.
  3. Enable Mac system control.
    Grant Accessibility permission, then enable the cursor. The display containing the Mac app is selected.
  4. Keep stopping simple.
    Control–Option–Command–P pauses. The Mac pause button and phone Stop button also stop control. Tracking loss releases held input.
